# Changelog

[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format; versions match [`plugin.json`](.claude-plugin/plugin.json).

## 0.1.1 - 2026-11-14

### Fixed

- The scene moves: SMIL animation in place of CSS transforms, which stood still in the app.

### Changed

- Faster and wider drift: 12 to 20 s cycles, glows also grow and shrink.
- Glass opacity 0.85 instead of 1, so the scene shows faintly through the panels.

## 0.1.0 - 2026-11-14

### Added

- Trial, dark mode only: Dracula colors over animated Purple, Pink and Comment glows on Background Darker.
- Opaque glass over panels (blur 64, opacity 1, tint Background); the scene shows around them.
